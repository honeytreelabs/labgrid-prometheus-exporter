# labgrid-prometheus-exporter

Labgrid Framework Prometheus Exporter.

## Installation

Install the project from the repository root:

```sh
uv sync
```

## Usage

Run the exporter command:

```sh
uv run labgrid-prometheus-exporter
```

The current command is a stub and prints a placeholder message.

## Development

Run the test suite:

```sh
uv run pytest
```

Build the package:

```sh
uv build
```
