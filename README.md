This repository contains tools that build on top of
[labgrid](https://github.com/labgrid-project/labgrid/). It is structured as
a toolkit workspace: reusable packages live under `packages/`, while
installable tools live under `apps/`.

At the moment the only app is the Prometheus exporter, but the repository
layout is intentionally prepared for additional labgrid-related tools
sharing the same backend and core packages.

## Apps

- [labgrid-prometheus-exporter](apps/prometheus-exporter/README.md) ...
  Prometheus exporter for labgrid coordinator state. It owns the
  `labgrid-prometheus-exporter` console script, Docker image, integration
  tests, and app-specific assets.

## Reusable packages

- [labgrid-toolkit-core](packages/labgrid-toolkit-core/README.md) ... shared
  metric/export loop code and the `CoordinatorBackend` contract.
- [labgrid-toolkit-backend-grpc](packages/labgrid-toolkit-backend-grpc/README.md)
  ... backend implementation for labgrid's gRPC coordinator protocol, used
  by labgrid >= 25.0.
- [labgrid-toolkit-backend-wamp](packages/labgrid-toolkit-backend-wamp/README.md)
  ... backend implementation for labgrid's WAMP/crossbar coordinator
  protocol, used by labgrid < 25.0.

## Development

This is a [uv workspace](https://docs.astral.sh/uv/concepts/projects/workspaces/).
The gRPC and WAMP backend packages require incompatible `labgrid` version
ranges, so a bare `uv sync` at the repository root is intentionally not a
valid workflow. Use the Makefile targets; they sync the matching package set
for each backend variant.

```sh
make test
make type-check
make lint
make build
```

`make test-integration` runs Docker-based end-to-end tests for the
Prometheus exporter and is intentionally separate from `make test`.
